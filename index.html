自动更新 Collector → DB → API → 前端（无种子数据中转，实时生效）

指标溯源示例

每个数字都可追溯

专利总量: 2,618 (分类后)

原始数据: EPO API 搜索 "AI chip" + IPC → 34,601条
分类匹配: IPC 前缀匹配到39个技术节点 → 2,618条
聚合: 自底向上, 父节点=子节点之和 (best-match)
前端: Stat Card 显示 root.patent_count = 2,618
可信度: 高 专利数据 + IPC匹配有据可查

论文总量: 21,602 (聚合后)

原始数据: OpenAlex API, 31节点×3关键词搜索 → 16,589条
去重: 按openalex_id/doi, per-node dedup → 14,933条
聚合: 父节点 = 自身 + Σ子节点 (multi-match, 无跨分支去重)
前端: Stat Card 显示 21,602 (含跨分支重复)
可信度: 高 但跨分支有重复计数

企业评分: NVIDIA 98分

计算: tech_strength×0.25 + market×0.25 + influence×0.25 + capital×0.25
tech_strength: ✓ 专利量log标准化
market_position: △ 缺市场份额数据
capital_investment: ✗ 7/66公司有真实融资额
可信度: 低-中 仅tech_strength有数据支撑

产品成熟度: H100 量产

原始数据: 公开规格页 (intuitionlabs.ai, flopper.io, Wikipedia)
提取: 手工整理 26款 × 17字段
关联: tech_node_ids 多对多映射
前端: 产品页 技术矩阵 + 时序 + 算力对比
可信度: 中 手工整理, 可能有遗漏
