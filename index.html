指标定义

每个分数从基础变量开始定义

patent_count (专利数量)
经IPC分类匹配到某技术节点的专利总数。每条专利按IPC前缀best-match到最细节点,然后自底向上聚合。
来源: 🟢 EPO API epo_collector.py
family_size (同族规模)
同一发明在不同国家/地区提交的专利家族成员数量。反映专利的商业价值和国际布局意愿。
来源: 🟢 EPO API family_id字段
overseas_ratio (海外布局占比)
企业在非本国提交的专利占其总专利的比例,衡量国际化程度。
来源: 🟢 EPO API country_code字段统计
patent_quality (专利质量, 0-100)
综合专利被引次数(citation_count)、同族规模(family_size)和海外布局占比(overseas_ratio),三项分别标准化到0-100后加权平均。
来源: 🟢 EPO API + 专利引用数据 · seed_ai_chip.py
tech_strength (技术实力, 0-100)
tech = min(100, log10(1+patent_count)×15 + patent_quality×0.4) · 专利数量(log)+质量,综合衡量企业在该技术节点的技术积累深度。
来源: 🟢 patent_count + 🟢 patent_quality
market_share (市场份额, 0-100%)
企业AI芯片相关业务营收 ÷ 全球AI芯片市场总营收 × 100。仅上市公司可通过年报(SEC EDGAR)获取,非上市公司从公开研究报告(Bloomberg/Visual Capitalist)或媒体报道推算。
来源: 🟡 SEC EDGAR + 🟡 Bloomberg · financial_collector.py
market_position (市场地位, 0-100)
market = 专利排名百分位×60 + market_share×40 · 若market_share缺则仅用排名百分位。
来源: 🟢 patent_count + 🟡 market_share
industry_influence (行业影响力, 0-100)
基于专利被引次数排名百分位计算。核心专利被大量后续专利引用说明该企业的技术具有基础性和引领性。
来源: 🟢 专利引用数据 · seed_ai_chip.py
vc_funding_million (累计融资额, M$)
企业自成立以来通过VC/PE/IPO累计融资总额,单位百万美元。从公开融资新闻、SEC文件、36氪报道中提取。
来源: 🟡 公开报道 + 🟡 SEC EDGAR · financial_collector.py
capital_investment (资本能力, 0-100)
cap = min(100, vc_funding_million/10) 若融资额已知; 或 min(100, log10(revenue_B+1)×20) 若营收已知; 若两者皆缺则无法计算。
来源: 🟡 vc_funding + 🟡 revenue
company_score (企业综合评分, 0-100)
score = tech_strength×0.25 + market_position×0.25 + industry_influence×0.25 + capital_investment×0.25
4维加权和,用于企业排名。6种角色权重可调,同一企业对不同视角的排名不同。
⚠ 当前可信度: 中 仅tech_strength完全自动化,market/capital依赖外部源
maturity_score (技术成熟度, 0-100)
vol = min(60, log10(1+patent_count)×15) — 专利量贡献(对数衰减)
div = min(25, log10(1+company_count)×10) — 参与公司多样性贡献
bal = 15×(1−|domestic_ratio−0.5|×2) — 国内外平衡度贡献
maturity = vol + div + bal · 在技术图谱页作为X轴展示
hidden_champion_score (隐形冠军指数)
6维加权模型,但4/6维度无真实数据支撑(客户供应链/成长性/国际化/曝光度)。
⚠ 当前不可信,前端页面已标注为BLOCKED

WWWW 核心框架

Tech Mining 回答了技术情报系统的四个核心问题:
Who is doing What, Where and When? — 以及 How (创新路径和关系网络)

Who (谁在做)

✅ 71企业 · 200专家 · 文献要求: 企业/专家/机构识别

What (做什么)

✅ 7L1×39节点 · 文献要求: 技术主题·路线识别

Where (在哪里)

⚠️ 国家分布有 · 产业链缺失 · 文献要求: 区域·供应链

When (什么时候)

✅ 年度趋势 · 缺: S曲线生命周期模型

文献建议: 两个待补充指标

1. 专利引用网络 — 识别核心技术专利和知识流动方向 (Porter强调的citation analysis)
可构建: ✅ 现有专利数据包含引用关系, 无需新数据源
2. 技术生命周期曲线(S曲线) — 用专利/论文增长率判断每个L2节点阶段
可构建: ✅ 年度趋势已用classified_yearly_trend, 可直接拟合S曲线

文献: Porter, A.L. & Cunningham, S.W. (2005). Tech Mining. Wiley. · Frontiers in Research Metrics and Analytics (2024)
