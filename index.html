指标计算说明

每个分数是怎么算的

技术实力 tech_strength 0-100

vol = min(60, log10(1+patent_count)×15)
qual = min(40, patent_quality/2.5)
tech_strength = vol + qual
含义: 专利数量(log)+质量综合
数据: 专利DB 自动计算

市场地位 market_position 0-100

rank_pct = 1 - rank/total
market = rank_pct×60 + share×40
含义: 专利排名百分位+市场份额
数据: 专利DB + 公开财务

影响力 industry_influence 0-100

citation_score = f(citation_rank)
influence = citation×0.5 + network×0.5
含义: 专利引用+合作网络中心度
数据: 专利引用 自动计算

资本能力 capital_investment 0-100

cap = min(100, funding_m/10)
或 min(100, log10(revenue_B)×20)
含义: VC融资额或营收(log)标准化
数据: 公开源 SEC/36氪/Bloomberg

公司综合评分 score 0-100

score = tech_strength×0.25
+ market×0.25 + influence×0.25 + capital×0.25
含义: 四维加权求和，用于排序
可信度: 中 仅tech_strength完全自动化

技术成熟度 maturity_score 0-100

vol = min(60, log10(1+PC)×15)
div = min(25, log10(1+CC)×10)
bal = 15×(1-|domestic_ratio-0.5|×2)
含义: 专利量+公司多样性+国内外平衡
数据: 专利DB 完全自动化

角色权重：不同视角看同一数据

系统定义6种角色，每个维度权重不同。同一家公司对于"投资者"和"政策制定者"的排名可能完全不同。

✓ 科研热度 论文数+趋势

△ 产业化程度 有产品数/缺营收出货
✗ 市场潜力/政策支持/资本关注/战略安全 缺数据源

主体综合评价 1/6真实

△ 技术能力 专利模型推算
✗ 产业化能力 缺营收/市场份额
✗ 影响力/成长性/风险修正
△ 国际化 专利国别可推

国家技术实力 3/7真实

✓ 科研基础/专利布局/头部企业
✗ 产业链完整度 全默认值
✗ 政策资本/标准话语权/供应链安全

隐形冠军识别 0/6真实

△ 赛道专注度/技术壁垒 模型推算
✗ 客户供应链/成长性/国际化/曝光度
⚠ 所有维度均不可信
